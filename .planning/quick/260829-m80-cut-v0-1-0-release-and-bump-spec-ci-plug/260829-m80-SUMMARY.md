rather than doubting the release.

## Open item this surfaced — the release does not reach `@v1` consumers yet

`spec-ci-plugin`'s Marketplace consumers pin `@v1`, a plain moving tag, and the tag-mover runs only
on `release: published`. Before this work `v1` pointed at `5adc903`, which was main's tip; main is
now `08cb520` and **`v1` still points at `5adc903`**.

So the default bump is merged but not yet reaching anyone using `@v1` — the same "reaches nobody"
failure mode that pinning `v0.0.3` created, one layer up. Closing it needs a `spec-ci-plugin`
patch release (v1.1.1), which is a Marketplace publish and a separate decision. **Left for the
maintainer.**
