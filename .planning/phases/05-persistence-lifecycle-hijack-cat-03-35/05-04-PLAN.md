<objective>
Ship the two arms whose attack and whose nearest legitimate document are grammatically identical and
differ only in what is being written: self-propagation, where the object is the instructions
themselves, and memory poisoning, where the object is the agent's own memory.

Purpose: D-02 settled self-propagation on measurement rather than principle — the attack and its
analogues were probed against `main` and found to be identical sentences differing only in object,
so the addressee cannot separate them and the object must. Memory is the same shape with a different
object, and `PATTERNS.md` rule 3 decides its grade against a real document rather than an imagined
one: Claude Code's own memory page describes exactly this behaviour as a product feature.

This plan also closes a hazard this repo has now hit three PRs in a row. Two bullets in
`docs/DETECTION-BACKLOG.md` quote these two payload shapes in double quotes, inside prose bullets
where no context downgrade applies, and `docs/DETECTION-BACKLOG.md` became a hard gate when it joined
`the_projects_own_documentation_is_clean`. The moment either pattern exists, the repo flags its own
documentation. The fix lands in the same commit as the pattern, not in review.

Output: `PI072`, `PI074` and `PI075` with load-bearing relaxed controls, the backlog bullets
code-spanned commit-for-commit with the patterns that reach them, the memory arm graded below the
commit-blocking tier on recalled evidence, and an adjudicated sweep delta.
</objective>
