<objective>
Ship the pattern this phase exists to produce, and the one that reaches hook abuse through prose.

Purpose: the ROADMAP's Phase 5 criterion *"at least one pattern detects an instruction to write into
a file the agent will re-read"* is measurably unmet today. `PI070` catches the addressee-bearing form
and misses the bare imperative, the passive, and the alternate instruction-file name — and the bare
imperative is the likeliest shape in a document an agent is merely pointed at. D-04 authorises
dropping the addressee requirement, and it is safe only because two other conjuncts replace it. Both
of those conjuncts were measured: without the determiner exclusion the pattern fires on the vendor
README shape, and without the durability cue it fires on three ordinary human-documentation
sentences, one of which is the shipped `counter_example`.

The prose hook arm has the opposite problem. Its bare form was measured firing on a host's own
documentation voice and on this repository's own `CLAUDE.md`, so it ships only in the agent-addressed
form, with the specimen that proves it in the corpus since plan 05-02.

Output: `PI073` as a three-conjunct pattern graded below the commit-blocking tier with its inherent
blind spot named in the file's own header, `PI076` requiring an AI addressee, each conjunct proven
load-bearing by its own mutation, and an adjudicated sweep delta.
</objective>
