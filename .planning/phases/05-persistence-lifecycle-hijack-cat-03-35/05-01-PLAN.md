| Boundary | Description |
|----------|-------------|
| corpus payload -> `frontmatter::extract`/`parse` | Attacker-shaped JSON and YAML enters the bounded parser on the same path a real scan takes |
| corpus payload -> recall harness | Test data governs a published security claim; a payload that fails to parse reads as a detection miss rather than a corpus bug |
| `README.md` recall table -> consumers | The published number is this tool's central claim; a table that drifts from `EXPECTED` is a false claim in the repo's own voice |
| sweep baseline -> every later `--compare` | A baseline captured from an edited tree, or compared against a JSON-free directory, silently produces a meaningless verdict |
