<decision_record>
**Category default severity is MEDIUM, not HIGH.** `04-PATTERNS.md` sketched the CAT-01 shape —
`default_severity: HIGH` with per-pattern overrides — but seven of this category's ten planned arms
are heuristic or supply-chain signals, and `PATTERNS.md` grades heuristics at MEDIUM by rule while
warning that HIGH is the severity `install-hook` blocks commits at. Setting the default to MEDIUM
means three explicit overrides in plan 04-05 rather than seven here and in 04-06, and it makes the
common case the safe case. D-03's requirement that config-hygiene signals sit below the
commit-blocking line is satisfied by construction rather than by seven separate fields each of which
could be forgotten.

**D-03's "unpinned `npx -y`" is implemented as an install-source signal, subject to measurement.**
`04-RESEARCH.md` §Q2 recorded plain unpinned package-runner installs as the ecosystem default across
forty-nine real manifests, naming five live examples. A pattern that fires on the ecosystem default
cannot pass the clean-corpus gate at any severity. D-03 is locked and is implemented — unvetted
server sources and unknown hosts are detected — but the discriminator is the install SOURCE rather
