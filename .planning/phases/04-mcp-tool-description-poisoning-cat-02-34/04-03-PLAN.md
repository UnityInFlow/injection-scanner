<objective>
Build the false-positive gate CAT-02's patterns will be judged against, and build it before the
patterns exist so it is a gate rather than a formality.

Purpose: the ROADMAP names CAT-02 the highest false-positive risk in the milestone, and
`04-RESEARCH.md` §Q3 measured why: a bare second-person probe already fires on a committed clean
specimen, and one widely deployed public MCP server writes essentially every tool description in
second-person imperative voice. `tests/corpus/clean/` is the only false-positive gate this repository
has, and the corpus rule forbids editing it to make a pattern pass. The correct move — the one
`.claude/skills/pattern-library/SKILL.md` records for issues #95 and #97 — is to add the specimen
that catches the over-widening first, then narrow the pattern against it.

Output: hand-written benign manifests sitting deliberately on D-01's boundary, a vendored public
registry sample with recorded provenance, a documentation specimen that quotes payloads and must
stay quiet at the default threshold, and a measured demonstration of where the two gates actually
look.
</objective>
