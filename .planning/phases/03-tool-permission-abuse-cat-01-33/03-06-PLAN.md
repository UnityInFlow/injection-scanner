Ship the prose half of CAT-01: persuasion to widen the agent's authority, at HIGH, through the
ordinary regex engine.

the document arguing for one. It is also where the category's real false-positive risk lives — a
permissions reference document and an operator runbook use the same vocabulary as the payload and
differ by provenance, which a regex cannot see. The five clean specimens committed in Plan 02 exist
precisely so this task finds that out at authoring time.

re-pinned, and the phase's user-visible documentation — including D-12's deliberate behaviour-change
note.
