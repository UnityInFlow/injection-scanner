  <action>
    Create `scripts/` (it does not exist) and write `scripts/gate03-sweep.sh`, a POSIX-shell script
    with `set -euo pipefail`.

    Interface. `scripts/gate03-sweep.sh <output-dir> <dir> [dir...]` sweeps each directory and writes
    one JSON report per directory into the output directory, named after a slugified absolute path,
    plus a `manifest.tsv` recording for each swept directory: the absolute path, the number of files
    the scanner actually scanned, and the number of findings. Plus a `summary.tsv` aggregating
    findings by pattern id and severity across all directories. A second mode,
    `scripts/gate03-sweep.sh --compare <baseline-output-dir> <candidate-output-dir>`, prints every
    finding present in the candidate and absent from the baseline, keyed on file path, line and
    pattern id, and exits 1 if that set is non-empty and 0 otherwise.

    Behaviour. Resolve the binary from `INJECTION_SCANNER_BIN` if set, else
    `target/release/injection-scanner`, and fail with a clear message if it is missing — the sweep
    must run the RELEASE binary over real directories, because unit tests substituting for the sweep
    is a recorded blocking anti-pattern in this milestone. Skip a directory that does not exist with
    a warning rather than aborting, and record the skip in the manifest, since the corpus is
    machine-local by nature. Pass `--format json`, `--all-files`, `--no-ignore` and
    `--exclude '.planning/**'` on every invocation. Treat the scanner's exit codes 0, 1 and 2 as
    successful runs — findings are the measurement, not a failure — and only a signal or a missing
    binary as an error. Parse the JSON with `python3` the way the pattern-library skill's one-liner
    already does, so no new dependency is introduced.

    With no arguments, print usage and exit 2.

    Constraints. The script must contain no verbatim injection payload text — this repository scans
    itself, and a new file outside `examples/`, `patterns/` and `tests/` carrying payload text would
    turn the self-scan red. Reference flag and key names only where the code requires them.

    Document at the top of the script, in comments: that the swept corpus is machine-local and
    therefore enumerated per run rather than pinned; that the meaningful output is the `--compare`
    delta between a pre-change and post-change run over the SAME directory list; and that this is
    the reconstruction of the manual procedure used for PR #103/#102.
  </action>
